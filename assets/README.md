# Qualitative assets

This directory contains the qualitative JPEG assets included with the anonymous submission package.

- `block_01` to `block_11`: 11 blocked case groups
- `pass_01` to `pass_06`: 6 passed case groups
- each case contains `source`, `input`, `output`, and `ours` images

`manifest.csv` records the relative paths and SHA-256 checksums for all 68 JPEG files.

# Qualitative assets

These are the JPEG assets supplied with the anonymous submission package.

- `block_01` … `block_11`: 11 case groups
- `pass_01` … `pass_06`: 6 case groups
- each case has `source`, `input`, `output`, and `ours` images

`manifest.csv` records file paths and SHA-256 checksums. The packaging step did **not** infer or reconstruct prompt text from the images. All 68 JPEGs were checked for EXIF metadata; none contained EXIF entries at packaging time.
